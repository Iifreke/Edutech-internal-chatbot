Comprehensive Project Report

Edutech Global AI Assistant (Skylar) Integration & Deployment

Date: May 2026 | Status: Deployment Ready

1. Executive Summary

The Edutech Global AI Assistant project was initiated to create a robust, autonomous, and brand-aligned AI knowledge base assistant for handling internal and user-facing queries. The project successfully delivered a Retrieval-Augmented Generation (RAG) powered pipeline integrated with a secure Supabase backend and an OpenRouter-driven LLM interface. Additionally, a comprehensive Admin Dashboard was developed to provide real-time lead management, document ingestion, and live escalation handling.

2. Project Objectives

  • Develop a Next.js web application functioning as an intelligent chatbot.
  • Implement a RAG pipeline allowing the AI to answer queries strictly based on proprietary Edutech Global documents.
  • Build a secure Admin Dashboard for document uploading, embedding generation, and knowledge base management.
  • Establish a live lead escalation system allowing human administrators to seamlessly intercept and respond to AI conversations.
  • Ensure strict visual alignment with Edutech Global corporate branding.

3. Technical Architecture & Stack

The solution was built utilizing a modern, highly scalable JavaScript ecosystem:

Next.js (App Router) React Supabase (PostgreSQL) pgvector OpenRouter API CSS/Tailwind

Core Infrastructure:

  • Vector Database: Supabase was configured with the pgvector extension to store document embeddings in an HNSW index, allowing for rapid semantic similarity search via custom SQL match functions.
  • AI Inference: OpenRouter was integrated to provide agnostic LLM access, routing prompts combined with retrieved document context to generate accurate, hallucination-free responses.

4. Key Features Implemented

4.1 RAG-Powered Pipeline

The system successfully ingests documents, chunks the text, and calculates vector embeddings. When a user asks a question, the assistant converts the query into a vector, queries the Supabase kb_chunks table for the highest semantic matches, and provides these chunks as context to the OpenRouter LLM. This ensures responses are highly accurate and restricted to Edutech Global knowledge.

4.2 Admin Dashboard & Authentication

A secure administrative panel was developed, accessible only via a configured environment password. This dashboard allows managers to:

  • Upload new PDF/TXT documents directly to the knowledge base.
  • Reprocess or delete existing documents to maintain data freshness.
  • Scrape relevant web URLs to immediately ingest external context.

4.3 Live Escalation & Lead Management

A critical business requirement was the ability to handle complex queries manually. We implemented a Supabase-polling mechanism that:

  • Flags conversations in the Admin Dashboard when the AI cannot resolve the issue.
  • Displays lead names directly within the conversation list for quick identification.
  • Allows admins to filter leads globally by school (including the implemented standardization of the "Babcock" university slug).
  • Enables admins to type a live response that is instantly pushed to the end-user's chat interface.

4.4 Branding Alignment

The entire application interface was audited and updated to reflect Edutech Global's corporate identity. This included applying the Primary Red (#D31E1E) and Primary Dark (#111111) color palette across all UI components, ensuring a professional and cohesive user experience.

5. Deployment Configuration

The project was configured for seamless deployment on Vercel or similar Node.js hosting platforms. All necessary environment variables (.env.local) were structured to include:

  • OPENROUTER_API_KEY
  • NEXT_PUBLIC_SUPABASE_URL
  • NEXT_PUBLIC_SUPABASE_ANON_KEY
  • SUPABASE_SERVICE_ROLE_KEY
  • ADMIN_PASSWORD

The Supabase schema initialization script (SUPABASE_SETUP.md) was successfully executed, establishing the kb_documents and kb_chunks tables, the pgvector extension, and the custom match_kb_chunks Postgres function.

6. Conclusion

The Edutech Global AI Assistant project has successfully reached operational readiness. The combination of advanced RAG techniques, a robust administrative backend, and a real-time escalation protocol provides a powerful tool for scaling customer interaction while maintaining the high quality and accuracy required by Edutech Global.
